## This repository is for centralizing scripts and config files.


```text
~/dotfiles/
├── bin/                   # Executables and scripts (add to PATH)
│   ├── note.sh
│   └── update.sh
├── nvim/                  # Neovim config (optional)
├── gitconfig              # Symlinked to ~/.gitconfig
├── zshrc                  # Symlinked to ~/.zshrc
├── install.sh             # Bootstraps everything on a new machine
├── README.md
```
